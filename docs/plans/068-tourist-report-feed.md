# Listado de reportes para turistas

En `/reportes`, quitar el encabezado visible y seleccionar «Ver todos» al entrar. Consultar el listado general sin estado y mantener los filtros de estado sobre ese listado. «Ver mis reportes» consulta el listado por el ID de la sesión.

Usar el cursor de cada consulta para mostrar más resultados y reiniciarlo al cambiar de filtro. Mantener la vista propia del panel para guías y prestadoras.

Probar el estado inicial, el cambio a reportes propios, el regreso al listado y la carga de otra página. Ejecutar typecheck, lint, tests y build.
