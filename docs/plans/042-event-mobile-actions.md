# Acciones móviles del catálogo de eventos

Añadir espacio para acciones junto al botón de FilterBar y clase opcional para las acciones de PageHeader. Solo eventos lo usa: enlace planificados en header desde 768px y junto a Filtros por debajo, siempre limitado a turista autenticado. Card desplegable permanece debajo. Permitir salto entre palabras del botón en pantallas estrechas.

Cambio de presentación reversible; sin tests nuevos que repliquen CSS. Ejecutar typecheck/lint/test/build. Skills normativas no disponibles según búsqueda previa.
