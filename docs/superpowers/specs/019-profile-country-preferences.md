# Presentación del perfil turístico

Información personal: País/Country lee nationality del perfil de turista; vacío o null muestra «—».
Preferencias: categorías en badges nombre + ×, distribuidos de izquierda a derecha y con salto de fila según ancho. Sin texto visible «Elegida por ti» ni botón separado «Quitar». El botón completo elimina la categoría, con aria-label localizado y disabled mientras guarda esa categoría. La nota general de inferidas se conserva.
