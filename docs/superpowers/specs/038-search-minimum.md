# Búsquedas

Escribir 1–2 caracteres conserva resultados previos sin consultar ni mostrar error rojo. A partir de 3 caracteres se consulta tras debounce. Vaciar permite volver al listado completo. El buscador global vacío no consulta. Las URLs con términos cortos no disparan búsquedas de catálogo. Filtros por IDs, estado, fecha y precio no tienen restricción de longitud.
