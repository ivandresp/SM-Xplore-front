# Navegación y fotos de atractivos

Tarjeta SiteCard: enlace nativo único hacia /atractivos/{id}, nombre accesible nombre del sitio, foto/nombre/zona dentro del enlace. Sin coordenadas ni botón. Hover borde/sombra, active fondo y foco visible. Miniaturas de galería siempre visibles justo tras contador cuando hay>1 foto; botones etiquetados con selección aria-pressed, teclado nativo.0 fotos fallback y1foto solo portada. No acordeón. Responsive grid existente sin mínimos nuevos. Sin cambios en otras tarjetas o API.
