# Selector de categorías

Dropdown SelectField existente con grupos General y Actividad/Evento. Opciones ordenadas por nombre, valor wire = nombre. Filtros permiten Todas las categorías; creación exige Selecciona una categoría. Excluir SITE/SERVICE y el scope ajeno. Mostrar carga, vacío y fallo con reintento local. No ofrecer entrada libre. Mantener el resto del formulario y los filtros.
