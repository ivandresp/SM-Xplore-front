# Registro de prestadoras

Empresa: NIT, fila Tipo de negocio + Fecha de inicio de operación, mapa Ubicación del negocio, Sitio web. Grid existente dos columnas desde 560px, una en móvil. Tipo de negocio opcional con tres opciones: Alojamiento, Transporte, Alimentacion. Sin hint previo. Mapa existente OSM con selección/limpieza, teclado, zoom y atribución. Sin inputs de latitud/longitud; selección no obligatoria.
