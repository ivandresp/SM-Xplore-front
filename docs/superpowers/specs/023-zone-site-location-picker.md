# Selector de ubicación del sitio

Alta y edición en Configurar zona usan mapa en lugar de inputs de latitud/longitud. Ninguna ubicación se guarda por defecto en alta; elegir punto es obligatorio. Los números seleccionados son los únicos que se envían como latitude/longitude.

Mapa responsive cuadrado hasta 384 px, atribución visible, marcador del valor guardado y ayuda ES/EN. Zoom y desplazamiento conservan el punto; seleccionar otro lo actualiza. Ratón/tacto: clic o toque marca, arrastre solo desplaza. Teclado: flechas desplazan y Enter/Espacio marcan el centro; botones cardinales equivalentes. Acciones del mapa nunca envían el formulario.

Sin tiles completos se bloquea nueva selección y se permite reintentar; se conservan selección previa y demás campos. Edición muestra ubicación actual. API y validación de rangos se mantienen.
