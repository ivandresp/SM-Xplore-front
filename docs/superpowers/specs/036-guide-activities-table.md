# Presentación de Mis actividades

Orden: Actividad, Categoría, Precio, Duración, Capacidad, Primera fecha, Estado, Acciones.
Las columnas de metadatos usan ancho intrínseco compacto y contenido sin saltos. El título usa entre 12 y 22rem según viewport y permite saltos entre palabras, sin truncamiento. Las acciones se mantienen en una fila centrada verticalmente. En pantallas estrechas se conserva el scroll local de DataTable.
