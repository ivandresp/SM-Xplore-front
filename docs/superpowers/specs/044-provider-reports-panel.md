# Panel de prestadoras y reportes

Reportes de seguridad abre /app/reportes sin desmontar el panel. Lista propia, crear/nuevo, detalle, volver/cancelar y éxito se mantienen dentro del shell. Enlaces anteriores /reportes redirigen a /app con consulta/fragmento conservados. Guía conserva comportamiento actual. Turista sigue público; admin/gestora conservan gestión. Sin nuevas acciones de moderación.
