# Card de evento

Catálogo público usa grid de tarjetas (mínimo13,5rem, reducible100%). Linknativo completo sin interactivos anidados, nombre accesible evento. Contenido: Media fallback actual sin poster; time badge sobre imagen con día/mes localizado y dateTimeISO; nombre h2, categoría y precio (Gratis si0). Sin hora, lugar, aforo, descripción ni botón. Estilo/gap/padding/foco equivalente a SiteCard, precio alineado al fondo. No cambiar filtros, query ni paginación. Mantener list/row/body/side compartidos con Planificados.
